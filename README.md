# Nikk Minor Projects
This is an area dedicated to various minor Python utilities that I have built and use for personal tasks. As a first app, I have uploaded a utility called **simple_disk_sync**. I am using a lot an external SSD and I needed simple (but custom) tool to sync the files of that disk with the Windows folder of my Desktop. So, there will be 2 folders: a folder hosted in my Desktop (the *Internal*) and another representing the SSD (the *External*). Syncing can go both ways and there are 2 options: I will simple refresh any file in the target that has been changed in the source, or I will also remove in the target any file that has been deleted in the source. Fresh files of the target remain always intact. I may also define folders that I would like to be ignored by the sync process.
